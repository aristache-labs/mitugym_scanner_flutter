# Sound Assets

This directory contains audio feedback files for the MituGym Scanner app.

## Required Files

- **success.mp3** - Played when check-in/check-out is successful
- **error.mp3** - Played when an error occurs

## Current Status

The current files are placeholders (empty files). To enable audio feedback:

1. Replace `success.mp3` and `error.mp3` with actual audio files
2. Recommended: Short beep sounds (< 1 second)
3. Format: MP3 or other formats supported by the `audioplayers` package

## Suggested Sounds

- **Success**: A pleasant, short "ding" or chime sound
- **Error**: A subtle "buzz" or error tone

You can find free sound effects at:
- https://freesound.org/
- https://mixkit.co/free-sound-effects/
- https://www.zapsplat.com/

## Disabling Audio

Audio feedback can be disabled in the app's Settings screen.
