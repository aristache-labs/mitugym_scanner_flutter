                        🚀 HOW TO CREATE INSTALLER
================================================================================

METHOD 1: EASIEST (RECOMMENDED FOR MOST USERS)
----------------------------------------------
1. Double-click: build_installer.bat
2. Choose option 1 (Inno Setup)
3. Wait for build to complete
4. Find installer in Output\ folder

That's it! 🎉


METHOD 2: COMMAND LINE (FOR DEVELOPERS)
----------------------------------------
Open PowerShell and run:
  .\build_installer.ps1 -InstallerType inno


METHOD 3: QUICK MSIX (FASTEST FOR TESTING)
------------------------------------------
Run these commands:
  flutter pub add msix --dev
  flutter build windows --release
  flutter pub run msix:create


METHOD 4: MANUAL INNO SETUP (MOST CONTROL)
-------------------------------------------
1. Download Inno Setup from: https://jrsoftware.org/isdl.php
2. Build: flutter build windows --release
3. Open installer_script.iss in Inno Setup
4. Click Build → Compile

================================================================================
                        ⚠️ IMPORTANT NOTES
================================================================================

1. SMARTSCREEN WARNING:
   → Users will see "Windows protected your PC"
   → This is NORMAL for unsigned apps
   → Users click: "More info" → "Run anyway"
   → For production: Get a code signing certificate (~$400/year)

2. FIRST BUILD TAKES LONGER:
   → Flutter needs to download dependencies
   → First build: 5-10 minutes
   → Subsequent builds: 2-3 minutes

3. TESTING:
   → Always test on a CLEAN Windows machine
   → Your development machine has all dependencies
   → Clean machine reveals missing DLLs/files

4. ANTIVIRUS:
   → Some antivirus may flag unsigned executables
   → This is normal, not a virus
   → Sign your app for production to avoid this

================================================================================
                         🛠️ CUSTOMIZATION
================================================================================

To customize your installer:

App Name & Version:
  → Edit pubspec.yaml (version: 1.0.0+1)
  → Edit installer_script.iss (lines 5-9)

Company Name:
  → Edit installer_script.iss (#define MyAppPublisher)
  → Edit windows\runner\Runner.rc (CompanyName)

App Icon:
  → Replace: windows\runner\resources\app_icon.ico
  → Format: .ico file with multiple sizes

Desktop Shortcut (Always Create):
  → Edit installer_script.iss
  → Remove "Tasks: desktopicon" from desktop shortcut line

================================================================================
                         🐛 TROUBLESHOOTING
================================================================================

"Flutter not found":
  → Add Flutter to PATH
  → Or use full path: C:\path\to\flutter\bin\flutter

"Inno Setup not found":
  → Download and install from: https://jrsoftware.org/isdl.php
  → Install to default location

"Build failed":
  → Run: flutter clean
  → Run: flutter pub get
  → Run: flutter build windows --release
  → Check: flutter doctor -v

"App won't start after install":
  → Install VC++ Redistributable 2015-2022
  → Download: https://aka.ms/vs/17/release/vc_redist.x64.exe
  → Or uncomment VC++ section in installer_script.iss

"Missing DLL errors":
  → Make sure ALL DLLs from build folder are packaged
  → Check installer_script.iss includes: Source: "*.dll"
